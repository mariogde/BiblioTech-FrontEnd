# 📚 BiblioTech - Front-End

Interface web para o sistema de gerenciamento de biblioteca **BiblioTech**, desenvolvida para consumir a API RESTful do projeto.

---

## 🛠️ Tecnologias

- **HTML5**
- **CSS3**
- **JavaScript**

---

## 📌 Funcionalidades Principais

- 📖 **Visualização de Acervo:** Interface para exibição e busca dos livros cadastrados.
- ➕ **Formulários de Cadastro:** Telas para inclusão de novos livros e usuários.
- 👥 **Listagem de Usuários:** Exibição dos leitores cadastrados no sistema.
